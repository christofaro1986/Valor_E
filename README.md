# Valor_E
Construção, Habilitação e Captura de Valor
A gestão estratégica não se encerra na formulação de objetivos. Para converter intenção em resultados, a organização precisa identificar as capacidades necessárias, constituí-las por meio de dimensões organizacionais, avaliar seu desempenho e orientar intervenções. O Valor-E estrutura essa relação em um processo integrado.
A abordagem considera duas perguntas distintas: em que medida as capacidades estão habilitadas para produzir os efeitos esperados? E em que medida essas capacidades contribuem para os objetivos estratégicos? A primeira é tratada pelo IHC; a segunda, pelo ICV. A distinção evita confundir capacidade disponível com resultado estratégico efetivamente alcançado.
